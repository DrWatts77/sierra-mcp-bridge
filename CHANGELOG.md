# Changelog

## 0.1.0 — Alpha candidate

- Exporter 1.6/schema 1 with saved IDs, independent defaults, exclusive writer
  claims and explicit-path support.
- Eight read-only MCP tools, bounded chart discovery, study metadata/values and
  up to 200 loaded history bars.
- Streamable HTTP/stdio, Entra OAuth and optional ngrok launcher.
- Optional NSSM services with dependency-ordered restart, account checks,
  idempotent enable and bounded startup-state verification.
- Synthetic contract, discovery, HTTP/auth, history and service tests; native
  Windows identity/file-lock tests.
- One-installation remote two-chart metadata/value acceptance reported.
  Independent installation and broader lifecycle/data-fidelity checks remain open.
